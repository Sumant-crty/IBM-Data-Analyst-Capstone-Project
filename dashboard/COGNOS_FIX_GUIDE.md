# Fixing the Cognos dashboard charts

## What is wrong

The survey stores multi-select answers as one text value, for example `PostgreSQL;Redis;SQLite`. Cognos treats each value as a single category, so the original technology charts counted **combinations** ("PostgreSQL;Redis") instead of technologies, and their counts are far too low.

The fix is to build the charts from a table that already has one row per technology:

| File | Rows | Use it for |
|---|---|---|
| `data/tech_counts.csv` | 294 | All 8 technology charts (languages, databases, platforms, web frameworks) |
| `data/demographics.csv` | 65,437 | Age, education and country charts |

Create them with `python scripts/make_cognos_tables.py survey-data.csv dashboard/data`. `tech_counts.csv` is already in this folder; `demographics.csv` is generated by the script (it is too large to keep in git).

## Steps

**1. Upload the files.** In Cognos Analytics, open the **+ New** menu (or the welcome page), choose **Upload files**, and upload `tech_counts.csv` and `demographics.csv`. They are saved to **My content**.

**2. Open the dashboard in edit mode.** Open **Survey Data dashboard** and switch **Edit** on.

**3. Add the new sources.** In the **Sources** panel (left side), click **+** (Add a source) and add both uploaded files.

**4. Rebuild each technology chart.** For each tile below, select the tile, open its **Fields** pane and set:

- **Bars / x-axis:** `Technology` (from `tech_counts.csv`)
- **Length / value:** `Respondents`, summarized as **Sum**
- **Local filters:** drag `Category` and `Status` into the tile's filters and pick the values in the table
- **Top 10:** on the `Technology` field, use **Top or bottom → Top 10 by Respondents**
- **Sort:** sort `Technology` by `Respondents`, descending

| Tab | Tile | Category | Status | Should show (top 3) |
|---|---|---|---|---|
| Current Technology Usage | Top 10 languages worked with | Language | Worked with | JavaScript 37,492 · HTML/CSS 31,816 · Python 30,719 |
| Current Technology Usage | Top 10 databases worked with | Database | Worked with | PostgreSQL 25,536 · MySQL 21,099 · SQLite 17,365 |
| Current Technology Usage | Top 10 platforms worked with | Platform | Worked with | AWS 22,191 · Azure 12,850 · Google Cloud 11,605 |
| Current Technology Usage | Top 10 web frameworks worked with | Web framework | Worked with | Node.js 19,772 · React 19,167 · jQuery 10,381 |
| Future Technology Trend | Top 10 languages wanted | Language | Want to work with | Python 25,047 · JavaScript 23,774 · SQL 22,400 |
| Future Technology Trend | Top 10 databases wanted | Database | Want to work with | PostgreSQL 24,005 · SQLite 13,489 · MySQL 12,269 |
| Future Technology Trend | Top 10 platforms wanted | Platform | Want to work with | AWS 18,040 · Azure 10,304 · Google Cloud 9,772 |
| Future Technology Trend | Top 10 web frameworks wanted | Web framework | Want to work with | React 15,404 · Node.js 14,735 · Next.js 8,507 |

If the numbers do not match the table, check the summary is **Sum** (not Count) and both filters are set.

**Chart types.** Use a **bar chart** for all eight. The word cloud and bubble pack showed combinations and are hard to read; a sorted bar chart shows the ranking at a glance. Give each tile a clear title from the table above.

**5. Demographics tab.** Point the tiles at `demographics.csv`:

- **Age:** `Age` with `ResponseId` as **Count**. Remove "Prefer not to say" with a filter if you want. Expect 25–34 years as the largest group (23,911).
- **Education:** `EdLevel` with `ResponseId` as **Count**. Expect Bachelor's degree as the largest group (24,942).
- **Country:** map or bar of `Country` with `ResponseId` as **Count**. Expect the US (11,095), Germany (4,947) and India (4,231) at the top.
- Exclude blank values in each tile's filters.

**6. Save and export.** Save the dashboard, then export each tab (**⋯ → Export → PDF**) and replace `survey-data-dashboard.pdf` in this folder. For screenshots, close the account menu first so your email address is not visible.
